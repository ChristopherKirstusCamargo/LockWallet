# Threat model (vivo)

Atualizar antes de cada gate que adiciona superfície. Formato (spec §3.3): ativo · vetor · defesa · teste · risco residual · gate.
Ativos: entropia/frase, seed de 64 B, chave Ed25519, DEK, pin_key, PIN, senha LWRP, blobs, LWRP, bytes assinados, histórico, destinatários confiáveis, seleção de rede.
