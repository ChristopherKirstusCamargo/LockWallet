# ADR 0004 — LWRP binário v1/v2, KDF, AAD e compatibilidade

- **Status:** Aceito — estrutura (Fase A) e cifra (Fase B, `LwrpCipher`) implementadas
- **Data:** 2026-11-19
- **Spec:** LOCK WALLET v2.0 + v2.1 + v2.2 (+ prompt 1.2 do proprietário); ver `docs/errata.md`.

## Contexto
Spec §10, v2.1 §2–3; revisão externa: janela 62 B–1 MiB contradiz payload fixo.

## Decisão
**Compatibilidade LWRP v1:** cabeçalho de 46 B (magic `LWRP`, versão 0x01, KDF `COMPAT_V1` = Argon2id v0x13/32 B, salt 16, m/t/p u32 BE, nonce 12); AAD = os 46 bytes. **LWRP v2 (novas gravações):** mesmo cabeçalho e payload, versão 0x02 e KDF `STRONG_V2` (m=65536 KiB, t=3, p=1). O leitor aceita somente os pares exatos versão/KDF: v1/COMPAT_V1 e v2/STRONG_V2; parâmetros fora da allowlist são recusados antes de executar Argon2id.

Payload 48 B (`LWPL`) + material. **Tamanho de arquivo exato** = 110 + material_length ∈ {126,130,134,138,142,174}; permanece igual nas duas versões e é validado antes de qualquer KDF (errata E-01). account_index ≥ 2^31 rejeitado. Flags ≠ 0 rejeitadas. Senha: NFC + UTF-8, 16–256 bytes; sugerido gerar 8 palavras (88 bits). Erros estruturais pós-decifragem são mapeados na UI para a mesma mensagem genérica.

## Alternativas rejeitadas
JSON; parâmetros KDF arbitrários; tamanho máximo genérico de 1 MiB.

## Consequências
Novas exportações usam v2; Recovery Packages v1 continuam restauráveis. Mudanças futuras de KDF/layout exigem novo par versão/perfil e vetores de regressão.

## Risco residual
Senha fraca continua atacável offline.

## Evidência
Fixture `lwrp-v1-structure.json` (implementação Python `struct` independente).

## Teste
`LwrpCipherTest` cobre fixtures v1, exportação v2 e leitura das duas versões; exportação via SAF grava, relê, compara, reabre com a senha e confere a pubkey. `LwrpStructureTest` mantém vetores de estrutura. Foram adicionados testes de round-trip v2 e leitura v1; pendentes de execução em CI/aparelho físico.

## Condição para reabrir
Necessidade de passphrase/multi-conta no pacote.
